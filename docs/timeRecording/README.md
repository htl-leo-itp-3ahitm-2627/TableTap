# Time Recording

This folder holds the time tracking of Team TableTap (Adyan, Valentina, Finn) for the ITP project. It is meant for our teachers, so they can see how much time each team member spent on the project and what they worked on.

> **Note:** The spreadsheet itself is written in **German**.

## File

[`Zeiterfassung_TableTap.xlsx`](Zeiterfassung_TableTap.xlsx)

| Tab | Content |
| :--- | :--- |
| **Anleitung** | Instructions for filling in the sheet, with one example entry |
| **Übersicht** | Hours per team member and per category, plus totals |
| **Adyan** | Adyan's time entries |
| **Valentina** | Valentina's time entries |
| **Finn** | Finn's time entries |

## Columns in each member tab

| German | English |
| :--- | :--- |
| Datum | Date |
| Von / Bis | From / To |
| Pause (min) | Break in minutes |
| Dauer (h) | Duration in hours (calculated automatically) |
| Kategorie | Category (Backend, Frontend, Design/Figma, Datenbank = database, Dokumentation = documentation, Meeting, Recherche = research, Testing, Sonstiges = other) |
| Tätigkeit | What was done |
